# Manual do usuário — Credenciamento

Este manual explica como usar a plataforma de credenciamento: o que cada módulo faz, quem costuma usá-lo e o passo a passo das ações do dia a dia.

O menu mostra somente o que o seu time permite. Se um item descrito aqui não aparecer para você, peça ao administrador para revisar as permissões do seu perfil em **Sistema → Perfis**.

## Como ler

1. Comece por [Primeiros passos](01-primeiros-passos.md) se ainda não entrou no sistema.
2. Use o índice abaixo para ir direto ao módulo.
3. Quando a tarefa atravessa várias telas (evento, serviço, mercadoria, bloqueio), leia também [Jornadas](09-jornadas.md).

Cada módulo segue a mesma estrutura: para que serve, quem usa, onde fica, o que a tela mostra, passo a passo e o que acontece em seguida.

## Quem costuma usar o quê

O acesso real depende do time. A tabela abaixo é um guia de operação, não uma regra fixa de perfil.

| Quem opera | Módulos mais usados |
|------------|---------------------|
| Portaria | Portaria, Registrar entrada, Registrar saída, Relatório de acessos |
| Empresa (gestor ou solicitante) | Acessos de Serviço, Credenciamento, Colaboradores, Frota |
| Produtora de evento | Eventos, Credenciamento, Colaboradores |
| Aprovador de setor | Aprovações, Times, Portaria (consulta) |
| Administração | Cadastros, Perfis, Usuários, Configurações, Auditoria, Gestão de bloqueio |

## Permissões

Cada módulo pode permitir **Visualizar**, **Criar**, **Editar** e **Excluir**. Ver a tela não garante poder salvar, aprovar ou apagar. O botão correspondente só aparece quando a sua permissão inclui aquela ação.
